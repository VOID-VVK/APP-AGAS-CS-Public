## [工具链] ProjectFilesTree 未感知外部文件变化，图片列表不会自动刷新

**日期**：2026-09-01
**现象**：在项目目录外部新增、重命名或删除图片后，`ProjectFilesTree` 仍显示旧目录内容；只有重新打开项目或手动触发扫描后才更新。
**根因**：文件树只在 `OpenProject` 时显式扫描目录，没有监听外部文件系统变化，也没有其他刷新触发路径。
**修复**：为每个 watcher 维护独立的 `FileSystemWatcher` 状态；外部变化经过 250ms 防抖后切回主线程重建文件树，并以窗口重新获得焦点作为兜底刷新。相同 root 复用 watcher；重建前后使用稳定的 selection bookmark 恢复选择，并在重建期间抑制选择信号，避免无效状态变更。已通过 `ProjectFilesTreeAcceptance`，并在真实 GUI 中验证外部创建/删除文件后列表自动更新且原选择保持。
**避免**：凡是展示磁盘目录的编辑器 UI，不要只依赖“打开项目时扫描”；应同时具备按 root 管理且可释放的文件监听、防抖、主线程 UI 更新、焦点兜底，以及基于稳定路径/标识的选择恢复。验收至少覆盖外部新增、重命名、删除和刷新后的选择保持。
